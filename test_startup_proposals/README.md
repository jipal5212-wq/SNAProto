## 🚀 How to Use During Judge Demonstration

### Option A: Uploading Directly to the SNAP Web Portal
1. Open [`http://localhost:5000`](http://localhost:5000).
2. Log in as a startup (`startup@demo.com` / `password`).
3. Click **Discover Challenges** -> Choose the open challenge.
4. Click **Apply to Challenge** -> Upload any of the `.docx` files from this folder.
5. Log in as an evaluator (`evaluator@demo.com` / `password`) -> Go to **Challenges** -> Click **⚡ Run AI RAG Shortlisting** to see the live scores, rankings, and doability badges!

### Option B: Uploading to the Standalone AI RAG Engine
1. Open [`http://localhost:5000/rag`](http://localhost:5000/rag) in your browser.
2. In **Step 1**, submit the problem statement.
3. In **Step 2**, upload the `.docx` files one by one using the file selector.
4. In **Step 3**, click **Get Shortlist** to see the 8-parameter score matrix!

### Option C: Google Docs Workflow
1. Open any `.md` file in this folder using Notepad or VS Code.
2. Select all (`Ctrl+A`) and copy (`Ctrl+C`).
3. Go to [docs.google.com](https://docs.google.com), create a new blank document, and paste (`Ctrl+V`).
4. Click **File -> Download -> PDF Document (.pdf)** or **Microsoft Word (.docx)**.
5. Upload the downloaded file into SNAP!
